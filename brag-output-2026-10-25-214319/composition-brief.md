# Composition Brief: Jarvis Control Center

Create a 20-second 1920x1080 landscape launch video for a premium local-first AI assistant. Use the actual Jarvis visual language: near-black blue background, faint technical grid, glass panels, cyan state light, restrained white typography, and a central reactive orb. The piece should feel like a confident product film, not a generic AI montage.

Use a single centered composition with a dashboard shell that evolves across five scenes. Show a realistic Jarvis interface with a left context rail, central orb, transcript/command area, and right activity rail. Use fictional command data only; do not include secrets, real accounts, or personal data.

The visual story is: boot → listen → reason → execute → lockup. Keep text sparse and readable. Use short labels: “LOCAL SESSION”, “LISTENING”, “FRIDAY BRAIN”, “TOOL SELECTED”, “EXECUTING”, “COMPLETE”, “GEMMA 4 E2B”, “OLLAMA”, and “STANDING BY”.

Use GSAP timelines and Hyperframes data attributes. Include the bundled track `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3` at low volume from `assets/music/`; use its cue metadata if available. Add only restrained interface SFX if the available assets are easy to reference. Ensure all visible text has strong contrast and remains within the 1920x1080 canvas.
